# MSCS532_Assignment1

## Course
MSCS-532-B01: Algorithms and Data Structures

## Assignment
Assignment 1: Getting Started

## Description
This project implements the Insertion Sort algorithm using Python.
The algorithm sorts a list of numbers in monotonically decreasing
order (highest to lowest).

## Example

Original Array: [12, 5, 9, 2, 18, 7]

Sorted Array: [18, 12, 9, 7, 5, 2]

## Running the Program

python3 insertion_sort.py

## Running Unit Tests

python3 -m unittest test_insertion_sort.py -v

## Time Complexity

- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)

## Space Complexity

O(1) auxiliary space.
